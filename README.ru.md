# WaterFaucet

VFX воды из-под крана для **Unreal Engine 5.8** — струя на Niagara с брызгами-каплями
и освещаемый полупрозрачный материал воды с регулируемыми **цветом, прозрачностью,
металликом, шероховатостью и бликом**.

Пакет содержит только контент: ни плагина, ни C++ модуля. Достаточно перенести ассеты в свой проект.

## Требования

| Пункт | Значение |
| --- | --- |
| Движок | **Unreal Engine 5.8** (ассеты сохранены в формате 5.8, в более старых версиях не откроются) |
| Плагин | **Niagara** (включён по умолчанию) |
| RHI | Желательно DX12 / Shader Model 6 (Lumen). В `Config/DefaultEngine.ini` задано `r.AllowStaticLighting=False` |
| Тип проекта | Только контент — **плагин и C++ модуль не нужны** |

## Состав

Все ассеты лежат в папке `/Game/VFX`.

| Ассет | Тип | Назначение |
| --- | --- | --- |
| `NS_Shower` | Niagara System | Сам эффект. Два эмиттера: **Stream** (струя) и **Splash** (капли в точке падения) |
| `M_Water` | Материал | Материал спрайтов воды: круглая маска капли, Default Lit + translucent; параметры `Color`, `Opacity`, `Metallic`, `Roughness`, `Specular`, `Brightness` |
| `MI_Water` | Инстанс материала | Пресет по умолчанию — голубая полупрозрачная вода без металлика |
| `MI_Water_Metallic` | Инстанс материала | Альтернативный пресет — серая, полностью металлическая (зеркальная) вода |
| `BP_ShowerHead` | Blueprint | Актор излива: меш + компонент Niagara, выставляет параметры |
| `L_ShowerDemo` | Уровень | Демо-сцена: небо, солнце, плоскость пола |

## Установка

Материал **Default Lit** — ему нужен свет: directional light + sky light (или Sky Atmosphere)
на уровне. Отражения берутся из сцены.

### Вариант А — скопировать папку (быстрее всего)

1. Скопируй `Content/VFX` в `<ТвойПроект>/Content/VFX`.
2. Сохрани путь `/Game/VFX/...` — ассеты ссылаются друг на друга по этому пути.
3. Перезапусти редактор (или нажми «Refresh» в Content Browser).

### Вариант Б — перенос через Migrate (надёжнее, тянет зависимости)

1. Открой `WaterFaucet.uproject` в UE 5.8.
2. В Content Browser выдели папку `Content/VFX`.
3. Правый клик → **Asset Actions → Migrate…** → подтверди список ассетов → укажи
   `<ТвойПроект>/Content`.
4. Ассеты окажутся в `<ТвойПроект>/Content/VFX`.

### Дальше

Перетащи **`BP_ShowerHead`** на уровень и нажми Play — или добавь `NS_Shower` в компонент
Niagara сам. Плоскость падения находится на `User.FallHeight` см ниже излива: подвинь актор
по высоте или измени это значение под свой пол.

## Использование

### Свойства `BP_ShowerHead` (Details, категория **Shower**)

| Свойство | По умолчанию | Смысл |
| --- | --- | --- |
| `Enabled` | `true` | Включает/выключает Niagara-компонент (своего рода «кран») |
| `Speed` | `600` | Скорость струи, см/с |
| `DropIntensity` | `1200` | Количество капель брызг |
| `DropSize` | `6` | Размер капель брызг |
| `WaterMaterial` | `MI_Water` | Материал спрайтов (см. *Известные ограничения*) |

Значения применяются Construction Script'ом актора к пользовательским параметрам Niagara ниже.

### Пользовательские параметры `NS_Shower`

| Параметр | По умолчанию | Смысл |
| --- | --- | --- |
| `User.Pressure` | `1` | Множитель напора/скорости (влияет на оба эмиттера) |
| `User.Speed` | `600` | Скорость струи, см/с |
| `User.SprayAngle` | `6` | Угол раскрытия струи, градусы |
| `User.SprayRadius` | `6` | Радиус струи, см |
| `User.FallHeight` | `200` | Расстояние от излива до плоскости падения, см |
| `User.DropIntensity` | `1800` | Капель брызг в секунду |
| `User.DropSize` | `8` | Размер спрайта капли брызг |
| `User.WaterMaterial` | `MI_Water` | Материал воды (см. *Известные ограничения*) |

### Параметры материала (`MI_Water`)

Открой `MI_Water` (или `MI_Water_Metallic`) и меняй значения в Details.

| Параметр | `MI_Water` | `MI_Water_Metallic` | Смысл |
| --- | --- | --- | --- |
| `Color` | `0.50 / 0.70 / 0.85` | `0.85 / 0.85 / 0.85` | Базовый цвет воды |
| `Opacity` | `0.6` | `0.65` | Прозрачность (`0` — невидимо, `1` — плотно) |
| `Metallic` | `0.0` | `1.0` | Металлик: подкрашивает отражения базовым цветом |
| `Roughness` | `0.05` | `0.08` | `0.02` — стеклянный зеркальный блик, `0.5` — матово |
| `Specular` | `0.8` | `0.6` | Сила блика для неметаллических поверхностей |
| `Brightness` | `0.4` | `0.6` | Слабое свечение, чтобы вода читалась в тени |

Быстрые рецепты:

* стеклянная/хрустальная вода — `Roughness` `0.02`, `Metallic` `0.1`, `Opacity` `0.5`
* прозрачнее — `Opacity` `0.35`, `Brightness` `0.2`
* молоко/пена — `Opacity` `1.0`, `Roughness` `0.4`, `Metallic` `0.0`
* жидкий металл — `Metallic` `1.0`, `Roughness` `0.05` (см. `MI_Water_Metallic`)

## Как это устроено

* **Эмиттер Stream** — спрайты, выровненные по вектору скорости, летят вниз от излива;
  Curl Noise добавляет дрожание, Drag тормозит. Размер спрайта, угол и радиус струи
  управляются пользовательскими параметрами.
* **Эмиттер Splash** — капли появляются в точке падения (`User.FallHeight` ниже излива),
  разлетаются в стороны под гравитацией с Drag, размер задаёт `User.DropSize`,
  альфа гасится по `1 - NormalizedAge`.
* **Форма капли** — в `M_Water` нет текстуры: круглая альфа-маска строится из UV спрайта
  через `SphereMask` и умножается в `Opacity`. Поэтому частицы выглядят каплями, а не квадратами.
* **Рендер** — translucent, two-sided, Default Lit: спрайты получают реальное освещение,
  блики и (при Lumen) отражения.

## Известные ограничения

* **Смена материала на конкретном акторе.** Свойство `WaterMaterial` у `BP_ShowerHead`
  (и параметр `User.WaterMaterial`) связано с рендерером через Niagara «Material User
  Parameter». Сохранённый в пакете биндинг имеет устаревший type handle, поэтому свежий
  материал игнорируется, пока один раз не выберешь `User.WaterMaterial` заново в выпадающем
  списке **Material User Parameter** у спрайтового рендерера в редакторе Niagara. До этого
  рендерер использует `MI_Water`. Надёжный способ поменять вид сейчас — править/менять
  **инстанс материала**.
* **Niagara не тикает во вьюпорте редактора** — проверяй эффект через **Play (PIE)**.
* Демо-уровень сделан с `r.AllowStaticLighting=False` (Lumen). При запечённом/статическом
  освещении вода будет выглядеть иначе.
